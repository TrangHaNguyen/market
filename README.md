# market

`market` is my independent research repository for stock-market prediction across multiple markets, with an initial focus on the U.S. and Vietnamese markets.

It is a standalone continuation of my earlier STAT 587 project, redesigned with a cleaner and more scalable structure for replication, cross-market comparison, and future extension.

This repository is currently under active development and should be treated as
an evolving research/codebase rather than a finished project. Structure,
features, and results may change as the work progresses.
